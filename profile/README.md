### Security Posture

- Protected `main` branches with linear history, stale review dismissal, code owner review requirements, and blocked force-pushes/deletions.
- Dependabot is enabled across maintained repositories for GitHub Actions and package ecosystems.
- Security issues are handled through private vulnerability reporting where available. Do not open public issues for suspected vulnerabilities.
- Releases and CI are expected to be reproducible, reviewable, and backed by local verification before merge.
